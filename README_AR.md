# منصة رحماء بينهم — نموذج أولي للموقع

## التشغيل
افتح ملف `index.html` مباشرة في متصفح حديث، أو شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ما يتضمنه النموذج
- صفحة رئيسية وهوية بصرية عربية متجاوبة.
- ست مبادرات تعريفية مع تصفية الفئات وتفاصيلها.
- نافذة توضيحية لتجربة التبرع بمبالغ دينار بحريني، مع تعطيل الدفع بالكامل.
- تعريف بالفريق ورؤيته، وصفحة تطوع وتواصل بنماذج اختبار لا ترسل البيانات.
- لوحة إدارة توضيحية بدون بيانات أو صلاحيات حقيقية.

## قبل النشر الرسمي
1. وضع الشعار الأصلي مكان عنصر `logo-placeholder` في رأس وتذييل الموقع.
2. تدقيق النصوص الرسمية وتصريح ISL-813 من مستنداته.
3. لا تحول أزرار الدفع إلى بوابة حقيقية حتى اعتماد وسيلة التحصيل ونطاق الترخيص والحساب البنكي.
4. بناء backend وقاعدة بيانات ومصادقة وتخزين آمن وسياسات خصوصية وتشغيل المراسلات.
5. استبدال البيانات التعريفية للحملات بمعلومات معتمدة.
6. تهيئة دومين مملوك للجهة وتثبيت شهادة TLS.

## ملاحظة
هذه واجهة أولية static prototype وليست منصة تبرعات إنتاجية. لا توجد أي معالجة أو إرسال لأموال أو نماذج.
